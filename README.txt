喵净到家｜网页版 + 可添加到手机主屏幕的 PWA 演示版

文件内容
- index.html：应用页面
- manifest.json：安装到主屏幕的应用配置
- sw.js：基础离线缓存
- icons/：应用图标

重要：我已生成可部署的 PWA 项目文件，但没有替你发布到公网，因此现在还没有一个已上线的公开网址。要通过网址打开并安装，需要先将整个文件夹部署到支持 HTTPS 的静态网站托管服务。

部署完成后
iPhone（Safari）：
1. 打开部署后的 HTTPS 网址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”，再点“添加”。

Android（Chrome）：
1. 打开部署后的 HTTPS 网址。
2. 打开浏览器菜单，选择“安装应用”或“添加到主屏幕”。

本机测试
由于 PWA 安装和 Service Worker 通常要求 HTTPS 或 localhost，不能只靠双击 index.html 验证安装功能。可用静态网站托管，或在电脑本地启动 HTTP 开发服务器后访问 localhost。

平台功能
- 用户端：选择服务、创建预约、查看/取消待接单预约
- 服务人员端：接受订单、开始服务、标记完成
- 管理后台：查看订单、修改演示订单状态、查看统计

生产环境限制
这仍是前端演示原型。订单只保存在当前浏览器的 localStorage；不同手机/浏览器之间不会同步。角色选择仅用于演示，不能作为安全权限控制。未接入真实账号、云端数据库、支付、短信/推送、真实服务者派单、身份核验或客服。正式运营前必须增加安全后端、权限校验、隐私与支付合规流程。
